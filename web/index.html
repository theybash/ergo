An agent is one Claude Code conversation, living in a folder on this laptop. Start one here and it appears as a card, awake, with its terminal streamed to this page.

A session you started by hand can add itself instead. Ask it to post its own session id to /api/agents/register and it will show up grey, ready to be woken.

This agent has not built a screen yet.

Agents write their own. Ask this one to write a module to views/<id>/view.js exporting render(root, platform), and it appears here.

More files mean more tabs. positions.js becomes a Positions tab, and a number in front sets the order: 10-positions.js comes before 20-pnl.js and the number is not shown.

Tell it to read DESIGN.md first. Ten agents with their own taste on one page look like ten products.

New agent

Two agents may share a folder. They are two conversations, not two copies of one.

Where this agent shows

Hidden, not locked. The point is somebody standing behind you at work, not an attacker: a hidden card's own address still opens, and its jobs still run.

Schedule work

The agent is woken when the job is due and put back to sleep afterwards, unless it was already awake. A job that was due while the laptop was shut is reported as missed and never run late.

Reporting is on by default, because the answer is usually the point of the job. Turn it down here and only failures reach the phone.

Undelivered
